# whenday

여러 명이 모이는 약속에서 **모두가 가능한 날짜를 빠르게 찾아주는** 모바일 우선 웹앱.

단톡방에서 "다들 언제 돼?"를 반복하지 않아도, 방장이 링크 하나만 공유하면 각자 가능한 날짜를 표시하고 전원이 되는 날을 한눈에 확인할 수 있습니다.

## 어떻게 동작하나

1. **방장이 약속을 만듭니다.** 제목과 날짜 범위를 정하고, 참여자 명단을 미리 등록합니다. 아무나 들어오는 게 아니라 등록된 사람만 참여해 혼란을 줄입니다.
2. **링크를 공유합니다.** 방장은 약속 링크를 단톡방 등에 공유합니다.
3. **참여자가 가능한 날을 표시합니다.** 링크로 들어온 참여자는 자기 이름과 색을 고른 뒤, 캘린더에서 가능한 날짜를 탭하거나 드래그해 표시합니다.
4. **전원이 되는 날을 확인합니다.** 모든 참여자의 응답이 캘린더에 색으로 누적되고, 전원 가능한 날이 강조됩니다. 누가 아직 입력하지 않았는지도 한눈에 보입니다.
5. **방장이 확정합니다.** 방장이 날짜를 확정하면 확정 화면이 만들어지고, 링크로 모두에게 공유할 수 있습니다.

날짜 단위로만 조율합니다(시간 단위는 다루지 않음). 모든 응답은 **실시간으로 동기화**되어, 다른 참여자가 입력하면 새로고침 없이 바로 반영됩니다.

## 화면 구성

| 경로 | 역할 |
| --- | --- |
| `/` | 랜딩(비로그인) / 내가 만든 약속 목록(로그인) |
| `/login` | 회원가입·로그인 |
| `/new` | 약속 생성 — 제목·날짜 범위·참여자 명단 |
| `/m/[id]` | 참여자 입장 — 이름·색 선택 |
| `/m/[id]/result` | 캘린더 — 가능한 날 입력 + 결과 확인 + 확정 |
| `/m/[id]/confirmed` | 확정된 날짜 공유 |

## 기술 스택

- **프레임워크**: Next.js 16 (App Router, Turbopack)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS (디자인 토큰 기반)
- **데이터 페칭**: TanStack Query v5
- **DB / Auth / 실시간**: Supabase (Postgres + Auth + Realtime)
- **날짜 유틸**: date-fns
- **바텀시트**: Vaul
- **아이콘**: lucide-react
- **폰트**: Pretendard
- **배포**: Vercel
